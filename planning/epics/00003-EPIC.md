# Adopt Shared Standards and Current Stable Fight Packages

## Destination

Adopt shared Agent OS engineering, planning, Pi skill, and delivery conventions by default while retaining Yii's
native composition and stronger local guarantees. Consume the latest verified stable Fight Common 1.4.0 and
AccessControl 0.8.0 contracts and verify owned Yii behavior through a thin build entrypoint and PHP phase
orchestration in a running Compose service, without weakening coverage or required hosted checks. Done means
all three requirement TICKETs have verified implementation; eligible parents complete automatically under
[local conventions](../CONVENTIONS.md#automatic-parent-completion), not through a separate closeout gate.

## Accepted decisions

The maintainer requested stronger Agent OS alignment, explicitly replacing disposable-image builds, in-gate
locked installation, and the separate disposable `--no-dev` installation. The maintainer chose this checkout and
requested EPIC/TICKET/TASK planning. Planning migration is the prerequisite standalone TASK-00007.

On 2026-10-24 the maintainer approved comprehensive adoption with Yii-specific exceptions, latest stable package
upgrades, and the main checkout on a feature branch. This amends the earlier `^1.2` / `^0.4` target to Common
`^1.4` / AccessControl `^0.8`, with 1.4.0/0.8.0 the verified release targets at approval. Inspect release/migration
guidance and exact installed contracts; do not infer compatibility from another consumer's versions. Recheck
release metadata at execution and surface any newer release outside the approved envelope for an explicit scope
amendment rather than silently selecting it. No development references, aliases, or unbounded upgrades.

Adopt shared standards, meaningful testing, instruction conventions, independent Review/QA, Build coordination,
Land, canonical evidence paths, and lightweight next routing through target-owned bindings. Preserve Yii providers,
DI, native routing, HTTP/console entrypoints, Twig, and selected adapters; provider Slim/PostgreSQL/frontend
implementation choices are not imported. Use installed provider resources by reference, not copied skills or
private paths. Concrete exceptions need an owner and rationale, not blanket opt-outs from shared guidance.

Adopt Common's shipped PHPCS standard with compatible consumer-owned tooling. Preserve exact 100% Unit-only
owned-production statement coverage, missing-file/ignore rejection, meaningful behavioral suites,
deployment-credential rejection evidence, and local/hosted gate parity. No provider coverage policy or
instruction-only adoption weakens these guarantees. No automatic Pi installation, enrollment, paid qualification,
source disclosure, release, or infrastructure provisioning follows from adoption.

## Scope and exclusions

Package contracts remain package-owned; Yii owns its selection, integration, gate, and documentation.
TICKET-00005/TASK-00012 owns shared conventions and target bindings, TICKET-00003/TASK-00008 owns stable
packages/PHPCS, and TICKET-00004/TASK-00009 owns gate/test-tooling changes. TASK-00011 records this planning
amendment separately. Do not duplicate those assignments or bulk-refactor unrelated source for conformity.
No package source copying, upstream publication, login, production persistence, queue delivery, browser workflows,
or release is authorized. This maintenance effort does not implement or complete the broader active Wayfinder map.
