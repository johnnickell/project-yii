# Align Stable Fight Dependencies and the Yii Development Gate

## Destination

Consume released Fight Common 1.2+ and AccessControl 0.4+ contracts and verify owned Yii behavior through a thin
build entrypoint and PHP phase orchestration in a running Compose service, without weakening coverage or hosted
checks. Done means both requirement TICKETs have verified implementation and explicit parent closeout.

## Accepted decisions

The maintainer requested stronger Agent OS alignment, explicitly replacing disposable-image builds, in-gate
locked installation, and the separate disposable `--no-dev` installation. The maintainer chose this checkout and
requested EPIC/TICKET/TASK planning. Planning migration is the prerequisite standalone TASK-00007.

Use stable Composer constraints `^1.2` and `^0.4`, not unbounded major upgrades, development references, or aliases.
Adopt Common's shipped PHPCS standard with compatible consumer-owned tooling. Preserve exact Unit-only production
coverage, behavioral suites, deployment-credential rejection evidence, and local/hosted gate parity.

## Scope and exclusions

Package contracts remain package-owned; Yii owns its selection, integration, gate, and documentation. No package
source copying, upstream publication, login, production persistence, queue delivery, browser workflows, or release
is authorized. This bounded maintenance effort does not implement the broader active Wayfinder map.
