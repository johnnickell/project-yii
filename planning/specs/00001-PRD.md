# Yii Starter Product and Walking-Slice Acceptance

## Local authority

This repository owns Yii-relevant product scope, walking-slice acceptance, architecture, documentation, and build
evidence. The external [Fight Common PRD-00016](https://github.com/johnnickell/fight-common/blob/develop/planning/specs/00016-PRD.md)
and [Fight Common PRD-00018](https://github.com/johnnickell/fight-common/blob/develop/planning/specs/00018-PRD.md)
are portfolio-bootstrap provenance only; they do not compete with Project Yii’s local planning or ticket status
authority. Local identifiers begin at `00001`; this repository currently has no local epic.

Yii owns native configuration providers, dependency injection, HTTP and console composition, Twig presentation,
and future persistence or operational adapters. Fight Common and Fight AccessControl are public Composer packages
only. There is no Fight bundle and no copied shared Domain or Application source.

## Bootstrap and acceptance boundary

The bootstrap establishes a governed hello-world foundation. Login, persistence, browser journeys, releases, tags,
Packagist publication, template enablement, and create-project distribution require separately adopted local
tickets. Acceptance is `./bin/build`, hosted CI delegating to that exact command, a native configuration/DI
integration check, governance checks, and a later immutable clean-clone receipt.
